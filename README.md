# 口算嘉年华（暂名）

每答对一道口算题，小熊猫的动作、画面特效和音乐就更热闹一层。答错不扣分、不掉气势，没有 Game Over，做完全部题目就是 100 分。

本项目是 [Dopa Drill（ドパドリル）](https://github.com/grmchn/dopa-drill)（作者 gear_machine，MIT 许可）的非官方中文改编版：界面全部中文化，吉祥物换成原创的小熊猫，字体换成可商用的中文开源字体。原版的角色「ドパキチ」和名称不包含在本项目中。

## 功能

- 小学一至六年级 58 个计算技能（加减乘除、竖式分步输入、小数、分数、百分数、比、解方程等），每次随机出题
- 我的闯关：首次做实力测试，之后按掌握情况自动解锁下一个技能
- 按年级练习、错题复习、技能树、每日任务、日历签到、补签锤、306 个奖杯、47 个可收藏特效
- 音乐和音效全部用 Web Audio 实时合成，不需要音频文件
- 手机竖屏和电脑都能玩，电脑上可以用数字键和退格键输入
- 记录只保存在本机浏览器里，不上传任何数据

## 本地运行

不需要构建，静态服务即可（ES Modules 不能用 `file://` 直接打开）：

```
python3 -m http.server 8000 -d app
```

浏览器打开 `http://localhost:8000/`。

## 测试

```
node --test tests/*.test.mjs
```

## 结构

| 路径 | 内容 |
| --- | --- |
| `app/` | 游戏本体（无依赖的 ES Modules） |
| `app/js/dopakichi.js` | 小熊猫的分层 SVG 与动作（动画引擎来自原版） |
| `docs/SPEC.md` | 原版规格书（日文） |
| `docs/zh-glossary.md` | 中文化术语表 |
| `tools/build_fonts.sh` | 改了界面文字后，重新生成字体子集 |

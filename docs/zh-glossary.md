# 中文化术语表（临时名，后续可统一替换）

面向小学生的简体中文。语气：亲切、简短、有活力，像游戏而不是课本。
原版日文为了照顾低年级大量用平假名、词间加空格（如「じぶんレベル」「すべて リセット」）；
中文不需要加空格分词，按正常中文书写即可（数字与汉字之间也不要加空格，除非原有排版需要）。

## 注意
- 只改面向用户的文字（字符串、aria-label、title、注释可不改）。不要改变量名、ID、CSS 类名、存储键名、数据结构、逻辑。
- 中文标点用全角（，。！？：「」），数字用半角。
- 日期/星期：日一二三四五六。
- 数字单位（万、億）：中文用 万、亿。「億」→「亿」。
